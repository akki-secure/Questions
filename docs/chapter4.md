## 第4章 開発プロセスとチーム開発（4問）

###  Q29. バージョン管理（Git）
質問:
1.Gitなどのバージョン管理システムとは何ですか？

2.なぜ必要ですか？

3.使わないとどんな問題が起きますか？

答え:
1.Gitとは、チーム開発で、同じファイルを複数人が編集する際に、いつ、誰が、何をしたかを追跡できたりするファイルの変更履歴を記録や管理する分散型バージョン管理システムのこと。

2.Gitは、チーム開発の時に、いつ、誰が、何をしたかを追跡できたり、前の状態に遡って戻せることも可能こともできるため必要だから。

3.Gitを使わない場合、PCにデータを保存したままにすると、トラブルなどが起きて、PCが壊れた場合、データが全て消えて大変な事態になるので、Gitを使って、リポジトリとして保存することで、データを安心して保存することができるから。

### Q30. ブランチとPull Request
質問:
1.ブランチとは何ですか？
2. Pull Request の目的は何ですか？
3.なぜ全員が main に直接変更しないのですか？

答え:
1.分岐したコミット履歴の先端を指すポインタ
2.自分コードなどをレビュアーにレビューにしてもらい、改善、提案など、共有して議論することが目的。
3.レビューなしで、コードが入り混じり、読みにくく、バグも発生したり、コンフリクトが発生する可能性があるから。


---

### Q31. コミットメッセージの重要性
質問:
例：`feat: ログイン機能を追加`
良いコミットメッセージを書くことがなぜ重要ですか？

答え:
チーム開発の時に、他のメンバーが、どういう機能を追加したのか、何を修正したのかと何を、何故変更したのかを理解でき、変更内容を把握しやすいから。


---


### Q32.なぜ技術的な仕組みを理解すべきか
質問:
AI時代においてコードはAIが書けるようになりました。それでも
- ネットワーク
- データベース
- Webアプリケーションの仕組み
を理解する必要がある理由を、あなたの考えで述べてください。

答え:
３つの仕組みを理解することで、アプリがどうやって動き、どのようにデータを保存するなど仕組みをアプリの構造をイメージすることで、トラブルが起きても、臨機応変に対応できるからだと思います。
